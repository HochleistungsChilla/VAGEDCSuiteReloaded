# I18N.md - Reloaded localization

UI-free internationalization for VAGEDCSuite-Reloaded. Targets **.NET Framework
4.0 / C# 4** (Windows XP SP3 .. Windows 11) and adds **no DLL dependency**:
`I18n.cs` uses only `mscorlib` and `System.dll` (`Microsoft.Win32.Registry`).
It does not reference Krypton, OxyPlot or DevExpress, so the orchestrator can
add it to `build.sh` without touching the reference list.

Status: new standalone files; `Main.cs`, `build.sh`, `Reloaded.csproj` and the
other owned files were not modified.

## Files

    Reloaded/I18n.cs            translation helper + flat-JSON reader
    Reloaded/locales/en.json    English (default)
    Reloaded/locales/de.json    German

`locales/` is resolved as `AppDomain.CurrentDomain.BaseDirectory\locales`, with
the executing assembly's directory probed as a fallback (Wine/Mono sometimes
reports a different base directory). The build does not copy the folder yet;
`build.sh`/`Reloaded.csproj` must ship `locales\*.json` next to `Reloaded.exe`
when this is wired in.

## Locale format

A flat JSON object, keys `snake_case`, values strings, UTF-8:

```json
{
  "window_title": "VAGEDCSuite-Reloaded",
  "checksum_report": "Checksum: {0}/{1} fields OK"
}
```

- **Flat only.** Values must be strings. Numbers, booleans, `null`, arrays,
  nested objects and comments are rejected (clear error with line/column).
- **Duplicate keys:** last one wins.
- **Escapes:** `\" \\ \/ \b \f \n \r \t \uXXXX`. A raw BOM at the start is
  tolerated; anything else outside the object is an error.
- **Placeholders** are ordinary `string.Format` slots (`{0}`, `{1:X}`). Values
  keep them untouched; `de.json` uses exactly the same slots as `en.json`
  (checked). Separators such as `"   |   "` live in the *code*, not the table,
  so they stay identical in both languages.
- **Missing key:** current language -> English -> the key itself. A missing
  translation can never blank out the UI.

## API

```csharp
using Reloaded;

I18n.Initialize();                       // optional: T() loads lazily
label.Text = I18n.T("window_title");     // plain lookup
label.Text = I18n.T("checksum_report", okFields, total);   // string.Format
I18n.SetLanguage("de");                  // apply + persist
I18n.LoadLanguage("de");                 // apply only, no persist
string saved = I18n.GetSavedLanguage();  // read preference, no side effects
string dir   = I18n.LocaleDirectory;     // where files are read from
string[] all = I18n.GetAvailableLanguages(); // e.g. ["de", "en"]
string err   = I18n.LastError;           // last load/persist failure or null
```

- `T(string key)` — current language, then English, then `key`. `T(null)` is
  `""`.
- `T(string key, params object[] args)` — `string.Format(CurrentCulture, ...)`.
  A malformed template returns its raw text instead of throwing.
- `LoadLanguage(code)` / `SetLanguage(code)` — return `false` and keep the
  previous table on an invalid code or missing/malformed file. Codes are
  lowercased and restricted to `[A-Za-z0-9_-]` (path separators rejected).
- `SetLanguage` persists best-effort: a registry write failure still switches
  the language and is reported via `LastError`.
- `LanguageChanged` event fires after a successful switch (handler exceptions
  are swallowed).
- Safe from any thread: the table is replaced wholesale under a lock, so a
  reader never sees a half-loaded dictionary.

## Persisted language

Registry, matching the existing theme store (`Theming.cs`):

    HKCU\Software\VAGEDCSuiteReloaded     "Language" (REG_SZ) = "en" / "de"

Absent, unreadable or implausible values fall back to **English**. A settings
file next to the exe was deliberately not used: the app already stores the
theme in `HKCU`, and the registry avoids write-permission problems in
`Program Files`.

On startup the lookup is lazy: the first `T()` call reads the persisted
language, else `en`. If the folder is unreachable it marks itself loaded (no
disk I/O per call); call `Initialize()`/`LoadLanguage()` again once the files
exist.

## Caveats

- The embedded parser is intentionally small: **flat string maps only**. If a
  future locale needs plural forms, nesting or arrays, use one flat key per
  variant (`gearbox_manual_fwd`) or add real plural logic in `I18n.T`.
- Both files must stay valid UTF-8; invalid bytes are replaced by U+FFFD by
  `StreamReader` instead of failing.
- No hot reload: a language change rebuilds the table, but already-assigned
  control texts keep their old value until the UI re-applies `T()` (the
  `LanguageChanged` event is the hook for that).
- `string.Format` culture is `CurrentCulture`; numbers in the info strip are
  formatted by `{1}`/`{1:X}` unchanged, so a culture with different digit
  grouping could change plain `{1}` — German and English do not here.
- Not wired: `build.sh`, `Reloaded.csproj`, `Main.cs` are untouched by design.
